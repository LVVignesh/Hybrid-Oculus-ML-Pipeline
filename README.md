# Hybrid-Oculus-ML-Pipeline
Advanced Hybrid ML Framework for Consumer Propensity. Integrates Unsupervised behavioral discovery (PCA/K-Means) with Gradient Boosted classification (XGBoost). Engineered for stability with 5-Fold Stratified CV and transparency via SHAP Explainable AI (XAI). Achieved 0.93 Mean ROC-AUC.
